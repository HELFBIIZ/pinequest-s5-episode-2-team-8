# Naadamy — Монгол өв соёлоо хамтдаа сурцгаая

**Pinequest · Pinecone Academy · Сэдэв: "Ирээдүйгээ тохируулъя — Эрүүл мэнд, боловсрол, ур чадварт тэгш хүртээмж" (Fine-Tune for the Future)**

Naadamy бол хүүхэд, гэр бүл, найзууд **Монголын өв соёлыг хамтдаа сурдаг** тоглоом. Апп нээгдэнгүүт шууд **Нутаг** пиксел тосгон руу орно. Хажууд чинь **Басар** хэмээх монгол банхар AI нохой үргэлж дагаж явж, асуусан бүхэнд хариулж, Монголын түүх, Нууц товчооны асуулт хариулт өгнө. Өв соёлын сургуульд **монгол гэр барих, цагаан идээ хийх, гэрийн ёс заншил, Нууц товчооны үлгэр**-ийг тоглож сураад, сурснаа гэр бүлээрээ бодит амьдрал дээр хийнэ.

> Ээж, аав нь "Тоглохоо больчих" гэхэд хүүхэд "Ээж ээ, хамтдаа монгол гэр барьцгаая!" гэж хариулдаг болох нь бидний зорилго.

## Ажиллуулах

Суулгах, бүтээх (build) алхам шаардлагагүй. Энэ хавтас дотроос:

```bash
node server.js
# дараа нь http://localhost:8000 хаягийг нээнэ
```

Mac дээр `start.command`, Windows дээр `start.bat` файл дээр давхар дарж ч асааж болно. Сервер ижил Wi-Fi-д холбогдсон утас, компьютерээс нээх хаяг болон QR кодыг хэвлэж харуулна. Node.js-ээс өөр юу ч суулгах шаардлагагүй.

Утсан дээр хуудсыг нээгээд "Нүүр дэлгэцэд нэмэх" (Add to Home Screen)-ийг сонгоно. Анх ачаалсны дараа интернэтгүйгээр ажиллана.

### 🐕 Басар AI-г асаах (сонголттой)
Басар түлхүүргүй үед ч **офлайн мэдлэгээрээ** (47 асуулт, 34 хариулт, сонирхолтой баримтууд) бүрэн ажиллана. Жинхэнэ AI ухаантай болгох бол:

1. https://console.anthropic.com хуудаснаас API түлхүүр авна.
2. `.env.example` файлыг `.env` нэртэй хуулж, `ANTHROPIC_API_KEY=` мөрөнд түлхүүрээ бичнэ.
3. `node server.js`-ийг дахин асаана. Терминалд `Basar AI: on (claude-opus-5-5)` гэж гарна.

- Түлхүүр **зөвхөн сервер дээр** хадгалагдана. Хөтөч, утас руу хэзээ ч илгээгдэхгүй. `.env` файл git-д орохгүй.
- Анхдагч загвар нь `claude-opus-5-5`. Өөр загвар хэрэглэх бол `.env`-д `BASAR_MODEL=...` гэж бичнэ.
- Зардлыг хамгаалахын тулд нэг төхөөрөмж минутад 10 орчим, бүх сервер өдөрт 1500 асуулт (`BASAR_DAILY_LIMIT`) хүртэл асууна.
- Сервер ажиллахгүй, интернэт тасарсан, эсвэл хязгаарт хүрсэн үед Басар автоматаар офлайн мэдлэг рүүгээ шилжинэ.

## Xcode, бүртгэл, лиценз шаардлагагүй

Naadamy бол энгийн вэб апп буюу PWA (Progressive Web App) юм. Үүнийг бүтээх, ажиллуулах, танилцуулах, суулгахад Xcode, Android Studio, Apple Developer бүртгэл, Google Play бүртгэл эсвэл ямар нэг төлбөртэй лиценз **хэрэггүй**.

- **Бүтээх хэрэгсэл хэрэггүй.** Зөвхөн HTML, CSS, JavaScript ашигласан. Хөрвүүлэх (compile) зүйл байхгүй, `npm install` хийх шаардлагагүй.
- **Гуравдагч талын сан ашиглаагүй.** Фонтууд `assets/fonts` хавтсанд багтсан, дуу авиаг кодоор үүсгэдэг. Апп өөрөө гадны сервер рүү хүсэлт илгээдэггүй. Цорын ганц үл хамаарах зүйл нь Басар AI: та түлхүүр тохируулсан үед Басарт асуусан асуулт манай сервер дамжин Claude руу очно.
- **Апп дэлгүүр хэрэггүй.** Утсанд хөтчөөс шууд суулгана:
  - **iPhone (Safari):** Хуваалцах товч → "Add to Home Screen".
  - **Android (Chrome):** цэс ⋮ → "Install app" эсвэл "Add to Home screen".
  Ингэсний дараа өөрийн дүрс тэмдэгтэй, бүтэн дэлгэцээр нээгдэж, офлайн ажиллана.

### Утсанд үнэгүй байршуулах
Офлайн горим болон дуу хоолой бичих функц **HTTPS** (эсвэл `localhost`) хаяг шаарддаг. Утсанд ашиглахын тулд хавтсыг дараах үнэгүй байршуулах үйлчилгээний аль нэгэнд тавина. Аль нь ч төлбөртэй багц, лиценз шаардахгүй:
- **Netlify Drop**: төслийн хавтсыг app.netlify.com/drop хуудас руу чирж оруулна.
- **GitHub Pages**: хавтсыг GitHub репозиторид оруулаад, тохиргооноос нь Pages-ийг асаана.
- **Cloudflare Pages** эсвэл **Vercel**: репозиторийг үнэгүй багцаар холбоно.

Нэг Wi-Fi сүлжээнд хурдан турших бол дотоод серверийг ажиллуулаад утсан дээрээ `http://<компьютерийн-IP>:8000` хаягийг нээнэ. Энэ аргаар офлайн кэш болон микрофоноос бусад бүх зүйл ажиллана.

## Агуулга

### Нэвтрэх, бүртгүүлэх
Хөдөлгөөнт пиксел тал нутаг (гэр, давхиж буй унага, хонь, гүйж буй Басар)-ийн дэвсгэр дээр хүүхэд:
1. **Нэрээ** бичнэ (Басар асууна).
2. **Насаа** сонгоно (3–18).
3. **Сахиус амьтнаа** сонгоно: хурдан морь, тэмээ, бүргэд, цоохор ирвэс, Бөртэ чоно, хонь, ямаа, сарлаг, цаа буга, үнэг, зурам, мазаалай. Амьтан бүр нэг сонирхолтой баримттай.
4. **3 нууц зураг**-аа сонгож профайлаа хамгаална (заавал биш). Үсэг уншиж сураагүй хүүхэд ч санахад хялбар. Мартвал том хүн математикийн асуулт бодоод арилгана.

Нэг төхөөрөмж дээр олон хүүхэд тус тусын профайлтай байж, "Нэвтрэх" хэсгээс өөрийгөө сонгоно.

### 🐕 Басар: монгол банхар AI найз
- Нутагт **үргэлж хажууд чинь** дагаж явна. Зогсоход хажууд чинь сууна. Хааяа "Вуф! Мэдэх үү?" гэж сонирхолтой баримт хуваалцана.
- Басар дээр дарах, 🐕 товч эсвэл **B** товчоор чат нээгдэнэ. Монголын түүх, Нууц товчоо, гэр, цагаан идээ, наадам, ёс заншлын талаар юу ч асууж болно.
- **Асуулт хариулт:** 6 сэдвээс (Түүх, Нууц товчоо, Монгол гэр, Цагаан идээ, Наадам, Ёс заншил) сонгоход 4 хувилбартай асуулт өгч, хариулсны дараа тайлбарлана. Зөв хариулт бүр Нутагт зоос, XP өгнө.
- **Хүүхдэд аюулгүй:** хувийн мэдээлэл асуудаггүй, хүүхдийн насанд тохирсон энгийн хэлээр 2–4 өгүүлбэрээр хариулна, түүхийг үнэн зөвөөр хэлж, мэдэхгүй бол "эмээ, өвөөгөөсөө асуугаарай" гэж зөвлөнө. Халуун сүү, зуух, хурц зүйлийг том хүнтэй хамт хэрэглэхийг сануулна.
- Хариулт бүр **AI** эсвэл **офлайн** гэсэн тэмдэгтэй тул эх сурвалж нь ойлгомжтой.

### 📚 Өв соёлын сургууль
Нутгийн **Сургуулийн гэр**-т ороход эсвэл 📖 товчоор нээгдэнэ. Хичээл бүр хөдөлгөөнт пиксел зурагтай: алхам бүрт гэр босч, сүү буцалж, үлгэрийн зураг солигдоно.

| Хичээл | Тоглож сурах зүйл | Гэр бүлээрээ хийх бодит ажил |
|---|---|---|
| ⛺ Монгол гэр барих | Шал → хана дэлгэх → хаалгыг урагш → тооно, багана → унь хатгах → эсгий → цагаан бүрээс → бүслүүр | Картон, шүдний чигчлүүр, даавуугаар бяцхан гэр барих |
| 🥛 Цагаан идээ хийх | Үнээ саах → сүүг халихгүй буцалгах → самарч өрөм гаргах → бүлээн болтол хөргөх → хөрөнгө хийх → дулаан боох → ааруул шахах, наранд хатаах | Гэртээ жинхэнэ тараг исгэх |
| 🙏 Гэрийн ёс заншил | Гэрийн дотоод зураг дээр хоймор, гал голомт, эрэгтэй ба эмэгтэй талыг олох, босго, нар зөв, багана | Эмээ, өвөөгөөсөө ёс заншил асууж, Дурсамжийн номонд бичих |
| 📜 Нууц товчооны үлгэр | Бөртэ чоно ба Гуа марал, Алан гуагийн таван сум, бяцхан Тэмүжин ба Өэлүн эх, Сорхон шар, 1206 оны Их хурилдай | Таван мөчрөөр эв нэгдлийн туршилт хийх |

- Хичээл бүр **Басарын 3 асуултаар** төгсөнө (AI эсвэл офлайн асуултын сангаас).
- Дараа нь **"Одоо бодит амьдрал дээр"** карт гарна: хүүхдийн хэлэх үг ("Ээж, аав аа, хамтдаа монгол гэр барьцгаая!"), хэрэгтэй зүйлс, алхмууд. Том хүн баталгаажуулахад гэр бүлийн +5 од, зоос, XP өгнө.
- **"Монгол гэр барих" хичээлийг дуусгасны дараа л Нутагт өөрийн гэрээ барих эрх нээгдэнэ.** Жинхэнэ малчид гэрээ өөрсдөө барьдаг шиг.

### 🏡 Нутаг: олон хүн хамт тоглох тосгон
Stardew Valley-гаас санаа авсан, монгол соёлтой 2D пиксел тосгон. Бүх зураг кодоор пиксел бүрээр зурагдсан өөрсдийн бүтээл.

- **Хамтын цэцэрлэг:** нэг өрөөний бүх хүн нэг цэцэрлэгт тарьж, усалж, хураана. Монголд ургадаг 7 ургамал.
- **Загасчлах:** алгана, цурхай, зэвэг, хадран (хамгаалагдсан тул буцааж тавина).
- **Наадмын дэлгүүр:** дээл, малгай, хадаг, тэжээвэр (хурга, банхар гөлөг, ботго…), тавилга.
- **Өөрийн монгол гэр:** гэр барих хичээлээ дуусгаад гэр хороололд гэр барьж, өнгийг нь сонгож, тавилгаар чимнэ. Найзууд зочилж болно.
- **Бөхийн барилдаан:** засуултай уулзаж, Наадамд барилдаж Начин, Харцага, Заан, Гарьд, Арслан, Аварга цол авна. Найзтайгаа шууд барилдана.
- **Овоо:** овоог тахиж, ёс заншлын талаар сурна.
- **Өдрийн даалгавар:** Басараас асуулт асуух, асуултад зөв хариулах, хичээл дуусгах, гэр бүлтэйгээ бодит ажил хийх, тарих, загасчлах гэх мэт.
- **Хөдөлгөөн:** WASD/сум товчоор 8 чиглэлд алхана, дэлгэц дээр дарахад очно. Space эсвэл E товч ойролцоох зүйлтэй харилцана.

### "Хиймэл оюун орлож чадахгүй" онцлогууд
- **Басар заана, гэр бүл хийнэ.** AI нохой мэдлэг өгдөг ч гэрийг ээж, аавтайгаа хамт барина. Хичээл бүр дэлгэцээс гадна дуусна.
- **Басар "эмээгээсээ асуу" гэдэг.** Мэдэхгүй зүйлээ ахмадуудаас асуухыг урамшуулна.
- **Дурсамжийн ном.** Эмээ, өвөөгийн ярьсан ёс заншил, түүх, дуу хоолойг бичиж хадгална. Бичлэгүүд зөвхөн төхөөрөмж дээр.
- **Эрүүл дэлгэцийн цаг.** Эцэг эхийн тохируулсан хязгаарт хүрэхэд апп амрах дэлгэц гаргаж, сурсан хичээлтэй холбоотой гэр бүлийн бодит ажлыг санал болгоно ("Ээж, аав аа, хамтдаа тараг исгэцгээе!").
- **Эцэг эхийн самбар.** Хүүхэд аль хичээлийг сурсан, аль бодит ажлыг гэр бүлээрээ хийсэн, Басарын асуултад хэдэн зөв хариулсан, өнөөдөр хэдэн минут тоглосныг харуулна.

### Тэгш хүртээмж
- Интернэтгүй хөдөө орон нутагт ажилладаг офлайн PWA. Басар ч офлайн мэдлэгтэй.
- Хуучин, хямд утсан дээр ажиллана. Монгол хэл үндсэн, англи хэл рүү сольж болно.
- Зар сурталчилгаагүй. Профайл, ахиц зөвхөн төхөөрөмж дээр хадгалагдана.
- Том үсэг, хөдөлгөөн багасгах горимтой.
- **Шударга үнэ:** Нутаг, бүх хичээл, Басарын офлайн мэдлэг үүрд үнэгүй. Сарын 3,900₮-ийн Гэр бүлийн багц Басар AI-г нээх бөгөөд тус бүр хөдөөгийн нэг хүүхдэд үнэгүй эрх олгоно. Төрийн сургууль, сумдад үнэгүй.

```
server.js              сервер: апп түгээх, Нутагт олон хүн холбох, /api/basar
basar-ai.js            Басарын Claude холболт (зөвхөн сервер дээр, түлхүүрийг нууцална)
sw.js                  офлайн кэш
tests/                 автомат шалгалтууд
.github/workflows/     GitHub Actions (шалгалт, GitHub Pages-д нийтлэх)
```

### Шинэ хичээл нэмэх
`js/learn/lessons.js` доторх `LESSONS` жагсаалтад нэг объект нэмнэ: `id`, `icon`, `title`, `desc`, `scene` (`ger`, `idee`, `inside`, `story`), `topic` (Басарын асуултын сэдэв), `steps` болон `family`. Алхмын төрлүүд: `learn`, `story`, `pick` (сонгох), `tf` (зөв/буруу), `tap` (олон дарах), `hold` (дараад барих), `timing` (цагаа олж дарах), `zones` (зураг дээр байрлал олох). Шинэ код бичих шаардлагагүй.

## Хамт тоглох (нэг Wi-Fi сүлжээнд)
1. Нэг компьютер дээр серверийг асаана:
   - **Mac:** `start.command` файл дээр давхар дарна.
   - **Windows:** `start.bat` файл дээр давхар дарна.
   - Эсвэл терминалд: `node server.js`
   (Node.js-ийг https://nodejs.org-оос үнэгүй суулгана.)
2. Сервер Wi-Fi хаяг (жишээ нь `http://192.168.1.25:8000`) болон **QR код** хэвлэнэ. Найзууд утасныхаа камераар уншуулахад шууд нээгдэнэ.
3. Нутагт дээд буланд байгаа холболтын товчийг дарахад **урилгын QR код** гарна. Энэ QR нь өрөөний кодыг агуулдаг тул уншуулсан хүн шууд ижил өрөөнд орно.
4. Анхдагч өрөө нь `NUTAG`. Гэр бүл, анги тусдаа тоглох бол нууц код (жишээ нь `BAT25`) сонгоно.

**Найзууд холбогдож чадахгүй бол:**
- Бүгд яг ижил Wi-Fi-д холбогдсон эсэхийг шалгана.
- Сургууль, зочны Wi-Fi ихэвчлэн төхөөрөмжүүдийг хооронд нь холбодоггүй. Ийм үед утасны **hotspot** асааж, бүгд түүнд холбогдоно.
- 8000 порт завгүй бол сервер автоматаар 8001, 8002… руу шилжиж, шинэ хаягаа хэвлэнэ.

Сервергүй үед (жишээ нь GitHub Pages) Нутаг ганцаараа горимоор ажиллаж, цэцэрлэг утсан дээрээ хадгалагдана.

## Арын хөгжим
Апп 22 ширхэг 8-бит адал явдлын дуутай (нийт 50 орчим минут). Бүгд **CC0 (нийтийн өмч)** лицензтэй, OpenGameArt.org-оос авсан тул ямар ч зорилгоор, төлбөртэй багцад ч чөлөөтэй ашиглаж болно. Зохиогчдын нэрс "Бидний тухай" хуудсанд харагдана.

- Дуунууд холилдон тоглогдож, хооронд нь зөөлөн шилжинэ. Богино дууг 2–3 удаа давтаад дараагийнх руу шилжинэ.
- Хэрэглэгч анх дэлгэцэд хүрэхэд эхэлж, апп арын горимд ороход зогсоно.
- Нутагт ♪ товчоор асааж унтраана. Эцэг эх самбараас дууны хэмжээг тохируулна.
- Дуунуудыг утсанд хөнгөн байлгахын тулд AAC (`.m4a`, 56 kbps, моно) болгож, дууны түвшинг тэнцүүлсэн. Нийт хэмжээ 15 MB орчим.

Шинэ дуу нэмэх бол файлаа `assets/music/`-д хийгээд `assets/music/playlist.json`-д нэмнэ:

```json
{ "file": "song.m4a", "title": "Дууны нэр", "artist": "Зохиогч", "license": "CC0", "source": "https://...", "repeat": 1 }
```

## Хүүхдийн аюулгүй байдал
- Нутагт бичгээр чатлах боломжгүй. Зөвхөн бэлэн найрсаг үг, эможи ашиглана.
- Басарын AI-д зөвхөн асуулт, хүүхдийн нэр, нас илгээгдэх бөгөөд сервер тэдгээрийг хадгалдаггүй. Системийн заавар нь хувийн мэдээлэл асуухгүй, аюултай сэдвээс татгалзаж, гунигтай хүүхдийг том хүнтэй ярихыг уриалахыг шаарддаг. Claude татгалзвал Басар эелдгээр өөр сэдэв санал болгоно.
- Зөвхөн ижил өрөөний кодтой хүмүүс бие биеэ харна. Сервер бүх мэдээллийг шалгаж цэвэрлэж, мессежийн тоог хязгаарладаг.
- Сервер зөвхөн өрөөний цэцэрлэг, гэрийг хадгална (`data/rooms.json`). Хүүхдийн ахиц зөвхөн төхөөрөмж дээр.

## Автомат шалгалт ба нийтлэл (GitHub Actions)

`.github/workflows/ci.yml` нь push болон pull request бүрт автоматаар ажиллана:

1. **JavaScript-ийн бичлэгийн шалгалт.**
2. **Файлын шалгалт** (`tests/check-assets.mjs`): бүх файл байгаа, офлайн кэшэд орсон, гадны сервер рүү хүсэлт илгээдэггүй эсэх.
3. **Хөтчийн шалгалт** (`tests/smoke.mjs`): Chrome-оор бүртгүүлж, нууц зургаар нэвтэрч, Нутаг, Басарын офлайн хариулт, асуулт хариулт, 4 хичээлийг эхнээс нь дуустал тоглож, гэр барих эрх нээгдэхийг шалгана.
4. **Олон тоглогчийн шалгалт** (`tests/multiplayer.mjs`): хоёр тоглогч хамт тарих, услах, ярих, гэр барих, барилдах.
5. **Басар AI-н шалгалт** (`tests/basar-api.mjs`): хуурамч Claude API ашиглан түлхүүр хөтөч рүү гарахгүй, зөв загвар, бүтэцтэй асуулт, татгалзлыг зөв зохицуулдаг, түлхүүргүй үед офлайн горимд ордгийг шалгана. Жинхэнэ түлхүүр шаардлагагүй.
6. **GitHub Pages-д нийтлэх.** `main` шинэчлэгдэх бүрт аппыг нийтэлнэ (Басар тэнд офлайн мэдлэгээр ажиллана).

```bash
node tests/check-assets.mjs && node tests/basar-api.mjs
npm install --no-save puppeteer-core@22.15.0 && node tests/smoke.mjs && node tests/multiplayer.mjs
```

## Шүүгчдэд үзүүлэх дараалал
1. Аппыг нээж, хөдөлгөөнт тал нутгийн дэвсгэр дээр **бүртгүүлнэ**: нэр, нас, сахиус амьтан, 3 нууц зураг.
2. Шууд **Нутаг** руу орж, **Басар** хажууд дагаж явахыг харуулна. Басар дээр дарж "Нууц товчоо гэж юу вэ?" гэж асууж, Нууц товчооны асуулт хариулт тоглоно.
3. Гэр хорооллын хоосон газар очиход "Эхлээд гэр барьж сур!" гэж гарна. Тэндээс **Монгол гэр барих** хичээлийг тоглож гэрээ алхам алхмаар босгоно.
4. Хичээлийн төгсгөлийн **"Ээж, аав аа, хамтдаа монгол гэр барьцгаая!"** картыг үзүүлж, бяцхан гэрийн бодит загварыг (урьдчилан хийсэн бол) харуулна.
5. Нутаг руу буцаж **өөрийн гэрээ барина**. Хоёр дахь утсаар найз нь нэгдэж гэрт зочилно.
6. **Цагаан идээ** хичээлээс сүү буцалгах алхмыг тоглоно (удаан барьвал сүү халина!).
7. **Эцэг эхийн самбар**-аас хүүхдийн сурсан хичээл, гэр бүлээрээ хийсэн ажлыг харуулна.
8. **Бидний тухай / Шударга үнэ** хуудсаар төгсгөнө.
